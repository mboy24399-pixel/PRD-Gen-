# PRD Forge

AI-powered Product Requirements Document generator.

## Status

Production-grade foundation under active development.

## Principles

- Secure BYOK Gemini integration
- Type-safe validation
- Server-side authorization boundaries
- Streaming generation with recoverable drafts
- Export-ready Markdown source of truth
- Automated quality gates

## Local development

Requirements: Node.js 20+

```bash
npm install
npm run dev
```

## Environment

Copy `.env.example` to `.env.local` and configure the required services.
